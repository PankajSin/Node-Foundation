In the Unicode character set, a plane is a contiguous structural group of exactly 65,536 code points.

The entire Unicode catalog is divided into 17 distinct planes (numbered Plane 0 to Plane 16), 
creating a total storage capacity of 1,114,112 possible character slots.

🔍 How to Identify a Character's Plane

You can find the exact plane of any character by looking at its hexadecimal code point format. 
Simply write the code point as 6 digits (padding with leading zeros if necessary) and look at the first two digits:

Example 1: The letter 'A' (U+0041)
Padded to 6 hex positions: U+000041
First two digits are 00 -> It resides in Plane 0 (BMP).

Example 2: The Waving Emoji '👋' (U+1F44B)
Padded to 6 hex positions: U+01F44B
First two digits are 01 -> It resides in Plane 1 (SMP).
