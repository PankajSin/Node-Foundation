how text characters map to these bytes (Encodings)?

1.ASCII
Size: Uses exactly 1 byte (7 bits active, 1 bit empty).
Capacity: Can only represent 128 characters.
Scope: Covers the English alphabet (uppercase and lowercase), digits 0–9, and basic punctuation.

 UTF-8 (The Modern Web Standard)
 Size: Variable-length encoding. It uses anywhere from 1 to 4 bytes per character.
 Capacity: Can represent over 1.1 million characters.
 Scope: Covers every language on Earth, emojis, and mathematical symbols. 
        It is fully backwards-compatible with ASCII (English letters still take exactly 1 byte).
